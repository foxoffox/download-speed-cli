# Замер скорости скачивания

Консольный скрипт для Node.js 22 и новее. Использует стандартную библиотеку, устанавливать пакеты не нужно.

Для проверки используй [тестовый файл OVHcloud в Рубе](https://lil1-rbx.speedtest.network.ovh.net/files/100Mb.dat). Размер файла — 100 МиБ, за полный прогон скачается 1000 МиБ.

```sh
node speedtest.mjs "https://lil1-rbx.speedtest.network.ovh.net/files/100Mb.dat"
```

Вместо примера можно подставить свою прямую HTTP(S)-ссылку. Скрипт скачивает файл десять раз подряд, дожидаясь конца каждого ответа. Файл читается порциями и нигде не сохраняется. Для каждого скачивания поддерживается до пяти HTTP-перенаправлений. При сетевой ошибке, обрыве ответа или статусе вне диапазона 2xx скрипт завершает замер с кодом `1`.

Скрипт выводит среднее время запроса в миллисекундах, общий размер тел скачанных ответов в байтах и скорость в **Мбит/с** (1 Мбит = 1 000 000 бит). Скорость равна общему объёму в битах, делённому на суммарное время запросов в секундах. Время включает ожидание ответа и перенаправления. HTTP-заголовки и служебный трафик в объём не входят.

Результат показывает скорость скачивания с выбранного сервера. Для устойчивого замера выбирай файл достаточно большого размера, чтобы время ожидания ответа составляло малую долю от времени скачивания. Скрипт скачает десятикратный объём файла.
